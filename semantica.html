Estructura semántica de HTML

HTML (HyperText Markup Language) es el lenguaje con el que se construye la estructura de una página web. Las etiquetas semánticas no solo muestran contenido: también indican qué significa cada parte (encabezado, menú, artículo, pie, etc.).

¿Por qué es importante?

Una buena estructura ayuda a las personas a leer la página, a los buscadores a entenderla y a las herramientas de accesibilidad (lectores de pantalla) a navegar mejor.

Etiquetas semánticas principales

EtiquetaUso
<header>Encabezado de la página o de una sección
<nav>Menú de navegación
<main>Contenido principal (solo uno por página)
<section>Bloque temático dentro del contenido
<article>Contenido independiente (noticia, entrada)
<aside>Información secundaria o relacionada
<footer>Pie de página o de sección

Ejemplo de estructura

<header> <h1>Mi sitio</h1> </header> <nav> <a href="index.html">Inicio</a> </nav> <main> <section> <h2>Tema</h2> <p>Contenido...</p> </section> </main> <footer> <p>Contacto</p> </footer>
Tip: evita usar solo <div> para todo. Si el bloque tiene un significado claro, usa la etiqueta semántica correspondiente.
