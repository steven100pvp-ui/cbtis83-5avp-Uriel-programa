Etiquetas semánticas HTML5

Esta página usa <header>, <nav>, <main>, <section> y <footer> (requisito de la lista de cotejo).

EtiquetaFunción
headerEncabezado del sitio
navMenú de navegación
mainContenido principal
sectionBloque temático
articleContenido independiente
footerPie de página

Ventajas

  • Código más claro y ordenado
  • Mejor para buscadores y accesibilidad
  • Estructura profesional de una aplicación web
