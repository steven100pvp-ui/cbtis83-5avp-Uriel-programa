Etiquetas y atributos HTML

Una etiqueta le dice al navegador qué tipo de contenido es. Casi siempre tienen apertura y cierre: <p>texto</p>. Algunas son de cierre automático, como <br> o <img>.

Etiquetas de texto e imagen

EtiquetaUso
h1 … h6Títulos (h1 es el más importante)
pPárrafo
brSalto de línea
strong / emÉnfasis fuerte / énfasis
imgImagen (src, alt)
div / spanContenedores (bloque / en línea)

Atributos frecuentes

  • id: identificador único (útil con JavaScript getElementById)
  • class: clase para CSS o getElementsByClassName
  • src y alt: en imágenes
  • href: en enlaces
  • style: CSS en línea (usar poco)
<h1 id="titulo">Mi página</h1> <p class="destacado">Texto importante</p> <img src="gato.jpg" alt="Foto de un gato" width="200">
Siempre incluye alt en las imágenes: describe la imagen si no se puede ver.
