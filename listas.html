Listas en HTML

Las listas organizan elementos en secuencia o en grupo. Hay tres tipos principales.

1. Lista ordenada (<ol>)

Muestra números o letras. Sirve para pasos, rankings o instrucciones.

<ol> <li>HTML</li> <li>CSS</li> <li>JavaScript</li> </ol>

Atributos: type (1, A, a, I, i) y start (número inicial).

2. Lista desordenada (<ul>)

Usa viñetas. Ideal para características o menús sin orden estricto.

<ul> <li>Windows</li> <li>Linux</li> <li>Android</li> </ul>

3. Lista de definición (<dl>)

Asocia un término (<dt>) con su descripción (<dd>).

<dl> <dt>HTML</dt> <dd>Lenguaje de marcado de hipertexto</dd> <dt>CSS</dt> <dd>Hojas de estilo en cascada</dd> </dl>
En JavaScript, las listas del DOM se pueden recorrer con ciclos (por ejemplo for) si necesitas procesar varios elementos <li>.
