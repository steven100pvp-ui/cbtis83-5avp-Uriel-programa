Introducción

En este proyecto se estudian los elementos principales para crear páginas web con HTML, CSS y JavaScript.

HTML organiza el contenido (títulos, párrafos, tablas, formularios, enlaces). CSS define la apariencia (colores, tipografía, espaciado). JavaScript agrega interactividad (preguntar datos, calcular, repetir acciones, cambiar la página).

Los temas de JavaScript de esta guía se basan en los ejercicios de práctica (suma, operaciones, condicionales, funciones, for, do while y DOM), explicados una sola vez por tema para no repetir.

Objetivo

Comprender fundamentos de HTML, CSS y JavaScript con ejemplos claros para crear páginas ordenadas e interactivas.
