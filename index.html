Bienvenida

Este proyecto une la teoría (explicaciones de HTML, CSS y JavaScript) con una aplicación web real que cumple la lista de cotejo: etiquetas semánticas, diseño responsivo, CSS externo, imágenes, video, listas, tablas, formulario con alertas e hipervínculos funcionando.

No es solo texto: cada requisito de la lista tiene un ejemplo visible y funcional en el sitio.

Mapa del sitio

  1. Etiquetas semánticas HTML5
  2. Imágenes y video
  3. Listas (ul, ol, dl)
  4. Tablas de datos
  5. Formulario + alerta
  6. Hipervínculos
