Ciclo for

El ciclo for repite un bloque un número definido de veces. Tiene tres partes: inicio, condición y incremento.

for (let i = 1; i <= 10; i++) { document.write(i + "<br>"); }

let i = 1 → empieza en 1
i <= 10 → se repite mientras i sea menor o igual a 10
i++ → suma 1 en cada vuelta

Ejemplo: repetir un nombre

let nom = prompt("Escribe tu nombre"); for (let i = 1; i <= 5; i++) { document.write(nom + "<br>"); }

Ejemplo: tabla de multiplicar

let numero = Number(prompt("Ingresa un número")); for (let i = 1; i <= 10; i++) { document.write(numero + " x " + i + " = " + (numero * i) + "<br>"); }

Ejemplo: repetir una palabra N veces

let cantidad = Number(prompt("¿Cuántas veces?")); for (let i = 1; i <= cantidad; i++) { document.write("Gato<br>"); }
Usa for cuando sepas cuántas veces se va a repetir.
