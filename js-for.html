Ciclo for

El ciclo for repite un bloque de código un número determinado de veces. Se usa cuando sabes (o puedes calcular) cuántas repeticiones necesitas.

Sintaxis

for (inicio; condición; incremento) { // código que se repite }
  • inicio — se ejecuta una vez al empezar (ej. let i = 1)
  • condición — mientras sea verdadera, se repite (ej. i <= 10)
  • incremento — se ejecuta al final de cada vuelta (ej. i++)

Contador del 1 al 10

for (let i = 1; i <= 10; i++) { document.write(i + "<br>"); }

Repetir un nombre 5 veces

let nom = prompt("Escribe tu nombre"); for (let i = 1; i <= 5; i++) { document.write(nom + "<br>"); }

Tabla de multiplicar

let numero = Number(prompt("Ingresa un número")); for (let i = 1; i <= 10; i++) { document.write(numero + " x " + i + " = " + (numero * i) + "<br>"); }

Repetir una palabra N veces

let cantidad = Number(prompt("¿Cuántas veces imprimir Gato?")); for (let i = 1; i <= cantidad; i++) { document.write("Gato<br>"); }
i++ significa i = i + 1. También puedes usar i += 2 para contar de 2 en 2.
Prácticas típicas con for: contador 1–10, nombre repetido, tabla de multiplicar, imprimir “Gato”.
