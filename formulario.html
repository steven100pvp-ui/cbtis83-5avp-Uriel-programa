Formularios HTML

Un formulario permite que el usuario escriba o elija datos y los envíe (registro, login, encuesta, búsqueda, contacto).

Elementos básicos

EtiquetaFunción
<form>Contenedor del formulario
<label>Texto descriptivo del campo
<input>Campo de entrada (texto, número, correo…)
<textarea>Área de texto largo
<select> + <option>Lista desplegable
<button> / submitEnvía el formulario
<fieldset> + <legend>Agrupa campos con un título

Atributos importantes de form e input

  • action: URL a donde se envían los datos
  • method: get (visible en la URL) o post
  • name / id: identifican el campo
  • type: text, number, email, password, checkbox, radio, date, color…
  • required: el campo no puede quedar vacío
  • placeholder: texto de ayuda dentro del campo
  • maxlength, min, max: límites

Ejemplo

<form action="#" method="get"> <fieldset> <legend>Datos personales</legend> <label>Nombre:</label> <input type="text" name="nombre" maxlength="40" required> <label>Edad:</label> <input type="number" name="edad" min="1" max="100"> <input type="submit" value="Enviar"> <input type="reset" value="Limpiar"> </fieldset> </form>
JavaScript se puede usar después para validar o procesar los datos del formulario antes de enviarlos.
