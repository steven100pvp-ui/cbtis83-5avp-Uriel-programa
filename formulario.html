Formularios HTML

¿Qué es un formulario?

Un formulario permite al usuario enviar datos a una página o a un servidor. Se usa para registros, búsquedas, encuestas y contacto.

Elementos importantes

  • <form>: contenedor del formulario.
  • <input>: campo de entrada (texto, número, correo, etc.).
  • <label>: etiqueta descriptiva del campo.
  • <textarea>: área de texto largo.
  • <select> y <option>: lista desplegable.
  • <button> o input type="submit": envía el formulario.

Atributos útiles

  • action: a dónde se envían los datos.
  • method: get o post.
  • name e id: identifican el campo.
  • required: obliga a llenar el campo.
  • placeholder: texto de ayuda dentro del campo.
  • type: text, number, email, password, checkbox, radio, date, color, etc.
<form action="#" method="get">
  <label>Nombre:</label>
  <input type="text" name="nombre" required>
  <input type="submit" value="Enviar">
</form>
Los formularios se combinan muy bien con JavaScript para validar datos antes de enviarlos, pero la base siempre es HTML.
