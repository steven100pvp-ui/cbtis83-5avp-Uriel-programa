Condicionales: if, else y switch

Las estructuras condicionales permiten que el programa decida: si se cumple una condición, ejecuta un bloque; si no, ejecuta otro.

if / else

let edad = Number(prompt("Escribe tu edad")); if (edad >= 18) { alert("Puedes votar. Edad: " + edad); } else { alert("Aún no puedes votar. Edad: " + edad); }

else if (varias opciones)

let num = Number(prompt("Escribe un número")); if (num > 0) { alert("Tu número es positivo"); } else if (num < 0) { alert("Tu número es negativo"); } else { alert("Tu número es cero"); }

Ejemplo: promedio

let nom = prompt("Nombre"); let mat = prompt("Materia"); let prom = Number(prompt("Promedio")); if (prom >= 6) { alert("APROBADO"); document.write("Nombre: " + nom + "<br>"); document.write("Materia: " + mat + "<br>"); document.write("Promedio: " + prom); } else { alert("REPROBADO"); }

switch (menú de opciones)

Útil cuando hay varias opciones fijas (1, 2, 3, 4…).

let n1 = Number(prompt("Número 1")); let n2 = Number(prompt("Número 2")); let ope = prompt("1 suma, 2 resta, 3 multi, 4 div"); switch (ope) { case "1": alert("Suma: " + (n1 + n2)); break; case "2": alert("Resta: " + (n1 - n2)); break; case "3": alert("Multiplicación: " + (n1 * n2)); break; case "4": alert("División: " + (n1 / n2)); break; default: alert("Opción no válida"); }
No olvides break en cada case; si no, sigue ejecutando los siguientes.
