Condicionales: if, else y switch

Permiten ejecutar código solo si se cumple una condición.

if / else

let edad = Number(prompt("Escribe tu edad")); if (edad >= 18) { alert("Puedes votar"); } else { alert("Aún no puedes votar"); }

else if (varias condiciones)

let num = Number(prompt("Escribe un número")); if (num > 0) { alert("Positivo"); } else if (num < 0) { alert("Negativo"); } else { alert("Cero"); }

switch

Elige una opción entre varias (útil en menús de operaciones).

let ope = prompt("1 suma, 2 resta, 3 multi, 4 div"); let n1 = Number(prompt("n1")); let n2 = Number(prompt("n2")); switch (ope) { case "1": alert(n1 + n2); break; case "2": alert(n1 - n2); break; case "3": alert(n1 * n2); break; case "4": alert(n1 / n2); break; default: alert("Opción no válida"); }
Ejemplos de práctica: votar (edad), promedio (aprobado/reprobado), mayor de dos números, semestre/laboratorio, positivo-negativo-cero, operaciones con switch.
