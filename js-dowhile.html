Ciclo do while

do while ejecuta el bloque al menos una vez y después sigue repitiendo mientras la condición sea verdadera.

Sintaxis

do { // código } while (condición);

Diferencia con for

fordo while
Ideal cuando conoces el número de vueltasIdeal hasta que se cumpla una condición
Contador i típicoValidar datos, contraseñas, menús
Puede no ejecutarse nunca (si la condición falla al inicio)Siempre corre mínimo 1 vez

Ejemplo: imprimir Hola 5 veces

let i = 1; do { document.write("Hola<br>"); i++; } while (i <= 5);

Pedir nombre hasta que no esté vacío

let nombre; do { nombre = prompt("Escribe tu nombre"); } while (nombre == ""); document.write("Hola " + nombre);

Contraseña correcta

Se repite mientras la clave sea incorrecta:

let clave; do { clave = prompt("Ingresa tu clave:"); } while (clave !== "1234"); document.write("Clave correcta. Acceso permitido");
Si escribes while (clave == "1234") el ciclo se comporta al revés. Para “hasta que sea correcta” usa !==.

¿Continuar? (sí / no)

let respuesta; do { respuesta = prompt("¿Quieres continuar? Escribe si o no"); } while (respuesta == "si"); document.write("¡Gracias por participar!");
