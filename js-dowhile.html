Ciclo do while

do while ejecuta el bloque al menos una vez y luego repite mientras la condición sea verdadera.

let i = 1; do { document.write("Hola<br>"); i++; } while (i <= 5);

Pedir un dato hasta que no esté vacío

let nombre; do { nombre = prompt("Escribe tu nombre"); } while (nombre == ""); document.write("Hola " + nombre);

Contraseña hasta que sea correcta

let clave; do { clave = prompt("Ingresa tu clave:"); } while (clave !== "1234"); document.write("Clave correcta. Acceso permitido");
La condición debe ser la de seguir pidiendo. Si la clave correcta es "1234", se repite mientras clave !== "1234".

Repetir mientras el usuario diga "si"

let respuesta; do { respuesta = prompt("¿Quieres continuar? si / no"); } while (respuesta == "si"); document.write("¡Gracias por participar!");
