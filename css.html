CSS: hojas de estilo en cascada

CSS (Cascading Style Sheets) controla la apariencia del HTML: colores, tipografía, espaciado, bordes y distribución.

Tres formas de aplicar CSS

FormaCómoRecomendación
En líneaatributo style="..."Solo casos puntuales
Interno<style> en el <head>Páginas pequeñas
Externoarchivo .css + <link>La mejor opción
<link rel="stylesheet" href="adorno.css">

Modelo de caja (box model)

Cada elemento es una caja con cuatro capas:

  1. content — el texto o imagen
  2. padding — espacio interior
  3. border — borde
  4. margin — espacio exterior respecto a otros elementos

Unidades comunes

  • px — píxeles fijos
  • % — porcentaje del contenedor
  • em / rem — relativos al tamaño de fuente
  • vh / vw — relativos al alto/ancho de la ventana
En este proyecto, adorno.css es la hoja externa compartida por todas las páginas. Así el diseño se mantiene uniforme.
