DOM y métodos básicos

El DOM (Document Object Model) es la representación de la página en forma de objetos. JavaScript puede buscar elementos y cambiar su texto, estilo o contenido HTML.

getElementById

Busca un elemento por su atributo id (debe ser único).

<h1 id="prueba">The Document object</h1> <script> let elemento = document.getElementById("prueba"); elemento.style.color = "red"; </script>

textContent e innerHTML

  • textContent — solo texto
  • innerHTML — puede incluir etiquetas HTML
document.getElementById("aviso").textContent = "Hola Estudiantes"; document.getElementById("mensaje").innerHTML = "¡Bienvenido!"; document.getElementById("imagen").innerHTML = '<img src="gato.jpg" width="100" alt="gato">';

getElementsByClassName

Devuelve una lista de elementos con esa clase. Se accede por índice [0], [1], …

const collection = document.getElementsByClassName("example color"); collection[0].style.backgroundColor = "lightblue";

querySelector

Usa un selector CSS y devuelve el primer elemento que coincida.

document.querySelector(".destacado").style.color = "red"; document.querySelector(".btn").disabled = true;

Eventos: responder a un clic

<h3 id="titulo">Mi primera página</h3> <button id="boton">Cambiar texto</button> <script> const boton = document.getElementById("boton"); const titulo = document.getElementById("titulo"); boton.addEventListener("click", function() { titulo.textContent = "¡Estoy aprendiendo JavaScript!"; }); </script>
