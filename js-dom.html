DOM y métodos básicos

El DOM (Document Object Model) representa la página como objetos. JavaScript puede leer y cambiar textos, estilos y elementos.

getElementById

<h1 id="titulo">Hola</h1> <script> let el = document.getElementById("titulo"); el.style.color = "red"; el.textContent = "Nuevo texto"; </script>

innerHTML

Cambia el contenido HTML de un elemento.

document.getElementById("mensaje").innerHTML = "¡Bienvenido!"; document.getElementById("imagen").innerHTML = '<img src="foto.jpg" width="100">';

getElementsByClassName

const lista = document.getElementsByClassName("ejemplo color"); lista[0].style.backgroundColor = "lightblue";

querySelector

Selecciona el primer elemento que coincida con un selector CSS.

document.querySelector(".destacado").style.color = "red"; document.querySelector(".btn").disabled = true;

Eventos (clic)

<button id="boton">Cambiar</button> <script> document.getElementById("boton").addEventListener("click", function() { document.getElementById("titulo").textContent = "¡Aprendiendo JavaScript!"; }); </script>
Métodos vistos en práctica: getElementById, getElementsByClassName, innerHTML, textContent, querySelector y eventos click.
