Hipervínculos (enlaces)

Un hipervínculo conecta una página con otra, con una sección, un correo o un archivo. Se crea con la etiqueta <a>.

Atributos principales

AtributoDescripción
hrefDirección de destino (obligatorio para navegar)
target_blank (nueva pestaña), _self (misma pestaña)
titleTexto al pasar el mouse
relRelación; con _blank se recomienda noopener

Tipos de enlaces

  • Internos: a otra página del mismo sitio (href="tablas.html")
  • Externos: a otro sitio (href="https://...")
  • Anclas: a un id de la misma página (href="#seccion")
  • mailto: abre el correo (href="mailto:correo@ejemplo.com")

Ejemplos

<a href="index.html">Volver al inicio</a> <a href="https://www.google.com" target="_blank" rel="noopener">Google</a> <a href="mailto:uriel@ejemplo.com">Enviar correo</a> <a href="#temas">Ir a temas</a>
El texto del enlace debe ser claro: mejor “Ver tablas HTML” que solo “clic aquí”.
