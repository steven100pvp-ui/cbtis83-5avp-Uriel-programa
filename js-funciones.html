Funciones en JavaScript

Una función es un bloque de código con nombre que realiza una tarea. Sirve para no repetir código y organizar el programa.

1. Función declarada (sin parámetros)

function mensaje() { alert("Bienvenidos a funciones de JavaScript"); } mensaje(); // llamada: ejecuta la función

2. Función con parámetros

Los parámetros son datos que la función recibe para usarlos dentro.

function saludo(nombre) { document.write("Hola " + nombre + "<br>"); } saludo("María"); saludo("Uriel"); // "nombre" es el parámetro; "María" y "Uriel" son los argumentos

3. Función con return

return devuelve un valor al lugar donde se llamó la función.

function suma(a, b) { return a + b; } let resultado = suma(5, 10); document.write("Resultado: " + resultado); // 15
Error común: definir function suma y llamar sumar(5,10). El nombre debe coincidir exactamente.

¿Para qué sirven?

  • Reutilizar la misma lógica varias veces
  • Separar tareas (una función = una responsabilidad)
  • Facilitar la lectura y el mantenimiento del código
