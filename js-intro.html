JavaScript: introducción y variables

JavaScript hace la página interactiva: mensajes, cálculos y cambios en el DOM.

Mostrar y pedir datos

alert("Hola"); let nombre = prompt("Tu nombre"); let ok = confirm("¿Continuar?");

Variables y números

let n1 = Number(prompt("Número 1")); let n2 = Number(prompt("Número 2")); alert(n1 + n2);

prompt devuelve texto; usa Number() para sumar correctamente.
