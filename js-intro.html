JavaScript: introducción y variables

JavaScript es el lenguaje de programación de las páginas web en el navegador. Con él puedes mostrar mensajes, pedir datos, calcular resultados y cambiar el contenido de la página.

Dónde se escribe

Normalmente dentro de la etiqueta <script>, al final del <body> o en un archivo .js externo.

<script> // Tu código JavaScript aquí </script>

Mostrar información al usuario

MétodoQué hace
alert("texto")Muestra una ventana emergente
document.write("texto")Escribe HTML/texto en la página
console.log("texto")Escribe en la consola del navegador (F12)

Pedir datos

  • prompt("pregunta") — el usuario escribe; devuelve un string (texto)
  • confirm("pregunta") — Sí/No; devuelve true o false
let nombre = prompt("Escribe tu nombre"); alert("Hola " + nombre); let continuar = confirm("¿Deseas registrar tus datos?"); if (continuar) { alert("Continuamos..."); } else { alert("Cancelado"); }

Variables

Una variable guarda un valor para usarlo después.

let edad = 17; // se puede cambiar después const PI = 3.1416; // valor constante let mensaje = "Hola"; // texto (string)

Operaciones y Number()

prompt siempre devuelve texto. Si sumas "5" + "10" obtienes "510" (concatenación). Para calcular números usa Number():

let n1 = Number(prompt("Primer número")); let n2 = Number(prompt("Segundo número")); let suma = n1 + n2; let resta = n1 - n2; let mul = n1 * n2; let div = n1 / n2; alert("Suma: " + suma);
En tus prácticas esto aparece en: suma, operaciones básicas, datos del alumno, promedio, edad para votar, etc.
