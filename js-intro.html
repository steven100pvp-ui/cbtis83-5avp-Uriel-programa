JavaScript: introducción y variables

JavaScript es el lenguaje que hace interactivas las páginas: puede pedir datos, mostrar mensajes, calcular y modificar el contenido.

Cómo se escribe en una página

<script> // aquí va el código JavaScript </script>

Mostrar información

  • alert("texto"): ventana emergente
  • document.write("texto"): escribe en la página
  • console.log("texto"): mensaje en la consola del navegador

Pedir datos al usuario

  • prompt("pregunta"): pide texto
  • confirm("pregunta"): sí / no (true o false)
let nombre = prompt("Escribe tu nombre"); alert("Hola " + nombre); let seguir = confirm("¿Deseas continuar?");

Variables

Guardan valores. Se declaran con let, const o (antiguo) var.

let edad = 17; const PI = 3.14; let texto = "Hola";

Números desde prompt

prompt siempre devuelve texto. Para sumar hay que convertir con Number():

let n1 = Number(prompt("Primer número")); let n2 = Number(prompt("Segundo número")); let suma = n1 + n2; alert(suma);
En los ejercicios de práctica esto se usa en: suma, operaciones, datos del alumno, promedio, votar, etc.
