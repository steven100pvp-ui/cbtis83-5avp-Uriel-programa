Tablas HTML

Las tablas organizan información en filas y columnas. Son ideales para horarios, calificaciones, precios o listas comparables.

Etiquetas de una tabla

EtiquetaSignificado
tableLa tabla completa
trUna fila (table row)
thCelda de encabezado (table header)
tdCelda de datos (table data)
captionTítulo de la tabla
thead / tbody / tfootAgrupan encabezado, cuerpo y pie

Atributos útiles

  • colspan: la celda ocupa varias columnas
  • rowspan: la celda ocupa varias filas
  • scope: asocia encabezados con celdas (accesibilidad)

Ejemplo

<table border="1"> <caption>Lista de alumnos</caption> <tr> <th>Nombre</th> <th>Edad</th> </tr> <tr> <td>Uriel</td> <td>17</td> </tr> </table>
Usa tablas para datos tabulares, no para diseñar el layout de toda la página. Para el diseño general es mejor CSS.
