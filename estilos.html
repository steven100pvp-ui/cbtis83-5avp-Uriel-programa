Estilos de hipervínculos con CSS

¿Para qué sirven?

CSS permite cambiar el color, el subrayado y el comportamiento de los enlaces cuando el usuario pasa el mouse o ya visitó la página.

Pseudo-clases de enlaces

  • a:link: enlace no visitado.
  • a:visited: enlace ya visitado.
  • a:hover: al pasar el mouse.
  • a:active: en el momento del clic.
a { color: #1565c0; text-decoration: none; }
a:hover { color: #0d47a1; text-decoration: underline; }
a:visited { color: #6a1b9a; }

Otras propiedades útiles

  • text-decoration: none, underline.
  • color: color del texto del enlace.
  • font-weight: grosor de la letra.
  • background-color: fondo del enlace (útil en botones).
