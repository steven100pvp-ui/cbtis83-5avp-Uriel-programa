Estilos de hipervínculos con CSS

Por defecto los enlaces son azules y subrayados. Con CSS puedes cambiar color, quitar el subrayado y definir qué pasa al pasar el mouse.

Pseudo-clases de enlaces

SelectorCuándo se aplica
a:linkEnlace no visitado
a:visitedEnlace ya visitado
a:hoverAl pasar el cursor
a:activeEn el momento del clic

Ejemplo práctico

a { color: #1976D2; text-decoration: none; } a:hover { color: #4CAF50; text-decoration: underline; } a:visited { color: #7B1FA2; }

Enlaces con aspecto de botón

.btn-link { background: #4CAF50; color: white; padding: 10px 16px; text-decoration: none; border-radius: 4px; } .btn-link:hover { background: #388E3C; }
Orden recomendado al escribir reglas de enlaces: link → visited → hover → active (LoVe HAte).
