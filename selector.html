Selectores y propiedades CSS

¿Qué es CSS?

CSS es un lenguaje que permite cambiar la apariencia de las páginas web. Se utiliza para modificar colores, tamaños de letra, espacios, bordes y la distribución de los elementos.

Tipos de selectores

  • Selector de etiqueta: aplica estilos a elementos como p o h1.
  • Selector de clase: nombre precedido por un punto (.bienvenida).
  • Selector de ID: identificador con numeral (#inicio).
  • Selector universal: el asterisco (*) selecciona todos los elementos.
  • Selector de atributo: por ejemplo input[type="text"].
p { color: #333; }
.bienvenida { text-align: center; }
#inicio { font-size: 24px; }

Propiedades CSS comunes

  • color, background-color
  • font-family, font-size, font-weight
  • margin, padding
  • border, border-radius
  • width, height, max-width
  • text-align, line-height

Ventajas de CSS

CSS permite separar el contenido del diseño. Esto facilita cambiar la apariencia de varias páginas sin tener que modificar cada uno de sus textos.
