Selectores y propiedades CSS

Un selector indica a qué elementos se aplica el estilo. Las propiedades definen qué cambia (color, tamaño, margen…).

Tipos de selectores

TipoEjemploSelecciona
Etiquetap { }Todos los <p>
Clase.bienvenida { }Elementos con class="bienvenida"
ID#inicio { }El elemento con id="inicio"
Universal* { }Todos los elementos
Descendentenav a { }Enlaces dentro de nav

Propiedades muy usadas

  • color, background-color
  • font-family, font-size, font-weight
  • margin (afuera), padding (adentro)
  • border, border-radius
  • width, max-width, height
  • text-align, line-height
p { color: #333; font-size: 16px; } .bienvenida { text-align: center; background-color: #4CAF50; color: white; } #inicio { font-size: 24px; }
La clase se puede repetir en varios elementos. El id debe ser único en la página (importante también para JavaScript).
